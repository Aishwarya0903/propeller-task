# Propeller Task

A React application scaffolded with [Create React App](https://github.com/facebook/create-react-app), currently in its initial setup stage.

## Status

🚧 Early-stage / scaffold. The project has been initialized with its dependencies and standard tooling, but application-specific features and components have not yet been built out.

## Tech Stack

- React 19
- Create React App (react-scripts 5.0.1)
- Testing Library (Jest, React Testing Library, jest-dom, user-event)

## Getting Started

Clone the repo and install dependencies:

\`\`\`bash
npm install
\`\`\`

Run the app in development mode:

\`\`\`bash
npm start
\`\`\`

Open [http://localhost:3000](http://localhost:3000) to view it in the browser. The page reloads automatically on changes.

### Other available scripts

- `npm test` — launches the test runner in interactive watch mode
- `npm run build` — builds the app for production to the `build` folder
